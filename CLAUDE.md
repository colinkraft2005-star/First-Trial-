# UCLA Basketball Analytics

Internal scouting and analytics platform for the UCLA basketball staff (Streamlit app, `app.py`).

## Style and conventions

- Never use em dashes in any output, code comments, or UI copy.
- UI theme is UCLA blue (#2D68C4) and gold (#F2A900).
- Scouting text renders as prose paragraphs, not bullet lists.
- Primary users are coaches and front office staff, not developers.
- Keep player comps realistic, never aspirational.
